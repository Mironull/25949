# Задание 9: создание двух процессов

Родитель создаёт подпроцесс, который выполняет `cat` для длинного файла, а сам
печатает свой текст. Из одного исходника `process_manager.c` собираются шесть
программ. Они отличаются только тем, ждёт ли родитель потомка, когда и каким вызовом.

```sh
make           # собрать все варианты и создать long_file.txt (2000 строк)
make demo      # запустить все варианты подряд, строки cat скрыты
./process_nowait long_file.txt
```

## Варианты

| Программа | Как ждёт родитель | Где последняя строка родителя |
|---|---|---|
| `process_nowait` | не ждёт (часть 1 задания) | обычно в самом начале, до вывода `cat` |
| `process_waitpid` | `waitpid(pid, &status, 0)` перед последней строкой (часть 2) | строго после `cat` |
| `process_wait` | `wait(&status)`: ждёт любого потомка, возвращает его PID | строго после `cat` |
| `process_waitid` | `waitid(P_PID, pid, &info, WEXITED)`: статус в `siginfo_t` | строго после `cat` |
| `process_wait_early` | `waitpid` сразу после `fork` | весь текст родителя после `cat` |
| `process_zombie` | не ждёт, но 2 секунды не завершается и показывает `ps` | после `cat`; потомок виден как `Z <defunct>` |

## Как читать вывод `make demo`

`make demo` прячет строки `cat`, но оставляет номера строк. Номер перед строкой
родителя показывает, где она оказалась в общем выводе. Если номер маленький (4),
строка вышла раньше `cat`. Если большой (2007), то после всех 2000 строк `cat`.

Вывод на Солярисе:

```
===== process_nowait
4:[PARENT] This is the last line printed by the parent.
===== process_waitpid
2007:[PARENT] This is the last line printed by the parent.
===== process_zombie
2006:  PID  PPID S COMMAND
2007:11636 11634 Z <defunct>
```
