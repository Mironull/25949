# Задание 9: создание двух процессов

Родитель создаёт подпроцесс, который выполняет `cat` для длинного файла, а сам
печатает свой текст. Первый аргумент программы задаёт режим: ждёт ли родитель
потомка, когда и каким вызовом.

```sh
make                                        # собрать и создать long_file.txt (2000 строк)
./process_manager nowait long_file.txt      # часть 1 задания
./process_manager waitpid long_file.txt     # часть 2 задания
make demo                                   # все режимы подряд, строки cat скрыты
```

## Режимы

| Режим | Как ждёт родитель | Где последняя строка родителя |
|---|---|---|
| `nowait` | не ждёт (часть 1 задания) | обычно в самом начале, до вывода `cat` |
| `waitpid` | `waitpid(pid, &status, 0)` перед последней строкой (часть 2) | строго после `cat` |
| `wait` | `wait(&status)`: ждёт любого потомка, возвращает его PID | строго после `cat` |
| `waitid` | `waitid(P_PID, pid, &info, WEXITED)`: статус в `siginfo_t` | строго после `cat` |
| `early` | `waitpid` сразу после `fork` | весь текст родителя после `cat` |
| `zombie` | не ждёт, но 2 секунды не завершается и показывает `ps` | после `cat`; потомок виден как `Z <defunct>` |

Без аргументов или с неизвестным режимом программа печатает подсказку со списком режимов.

## Как читать вывод `make demo`

`make demo` прячет строки `cat`, но оставляет номера строк. Номер перед строкой
родителя показывает, где она оказалась в общем выводе. Если номер маленький (4),
строка вышла раньше `cat`. Если большой (2007), то после всех 2000 строк `cat`.

Вывод на Солярисе:

```
===== nowait
4:[PARENT] This is the last line printed by the parent.
===== waitpid
2007:[PARENT] This is the last line printed by the parent.
===== zombie
2006:  PID  PPID S COMMAND
2007:11799 11797 Z <defunct>
```
