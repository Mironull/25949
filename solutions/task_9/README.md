# Задание 9: создание двух процессов

Программа `process_manager` создаёт подпроцесс, который выполняет `cat` для
длинного файла. Родитель в это время печатает свой текст.

```sh
make                                   # собрать программу и создать long_file.txt (2000 строк)
./process_manager -n long_file.txt     # первая часть: без ожидания
./process_manager long_file.txt        # вторая часть: с waitpid
```

То же самое делают `make nowait` и `make wait`.

## Что должно получиться

- С ключом `-n` родитель не ждёт ребёнка. Его последняя строка может появиться
  посреди вывода `cat`, а приглашение shell может вернуться раньше, чем `cat`
  допечатает файл.
- Без ключа родитель вызывает `waitpid`. Строка «Это последняя строка…» всегда
  идёт после `Line number 2000 of the long file`, перед ней выводится код
  завершения ребёнка.
